Explicação do Projeto:
SPA Deluxe é uma aplicação desenvolvidas em C (paradigma imperativo) e Python - programação orientada a objetos que simula o atendimento de clientes em um estabelecimento de estética e bem-estar.
O projeto tem como objetivo aplicar os conceitos aprendidos em aulas. Nesse projeto por meio de um menu interativo, o cliente pode selecionar um serviço, visualizar seu preço, receber descontos automaticamente e consultar o resumo do atendimento.
